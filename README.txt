# Meke Financial Services Cash Loan Website

## Included
- Responsive cash-loan website
- Meke promotional flyer supplied by the client
- Requirements section
- Online application form
- WhatsApp application button
- QR code that opens WhatsApp with a pre-filled application message
- Contact details from the supplied flyer

## WhatsApp QR destination
https://wa.me/264813027355?text=Hello%20Meke%20Financial%20Services.%20I%20would%20like%20to%20apply%20for%20a%20cash%20loan.%20Please%20send%20me%20the%20application%20requirements.

## Important
The website currently uses the 30% interest figure shown on the supplied promotional flyer. Before publishing, confirm the actual interest rate, fees, loan terms, eligibility rules, privacy notice, and regulatory requirements with the business.

## To run
Open `index.html` in a browser.

## To publish
Upload the whole folder to your chosen web host. Keep the `assets` folder in the same location as `index.html`.
